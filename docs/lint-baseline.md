# Lint baseline decisions

`apps/android-tv-host/app/lint-baseline.xml` is generated by Android lint and
contains five reviewed findings. It is not a general suppression list: CI
treats every new non-dependency warning as an error.

| Finding | Current disposition |
| --- | --- |
| `OldTargetApi` | Target SDK 34 remains intentional until the next platform migration is tested on the API 26 minimum, the current TV image, and physical playback hardware. |
| `DiscouragedApi` | The player activity is TV-only and intentionally landscape. The manifest requires Leanback and does not claim phone/tablet support. |
| `ChromeOsAbiSupport` | Release APKs intentionally ship ARM TV ABIs only. Debug builds carry x86/x86_64 for managed and local emulators. ChromeOS is not a supported release target. |
| `VectorRaster` | The 320×180 vector is the TV launcher banner size, not a small in-app icon. It remains until a visually verified density-safe raster replacement is prepared. |
| `VectorPath` | The same banner contains a long wordmark path. It is accepted with the banner-specific performance caveat above. |

Recreate the file only after reviewing every emitted issue:

```bash
source scripts/android-env.sh
cd apps/android-tv-host
./gradlew :app:updateLintBaseline
git diff -- app/lint-baseline.xml
./gradlew :app:lintDebug
```

Do not use baseline regeneration to make an unrelated CI failure disappear.
